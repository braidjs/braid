C · The realm document, written in the browser

<!doctype html><meta charset="utf-8">
<title>Braid realm: braided</title>
<meta name="braid-protocol" content="2">
<base href="https://this-page/f/braided/">

→ new Blob([html], { type: 'text/html' })
→ URL.createObjectURL(blob)   blob:https://this-page/51d2…
→ iframe.src = blobUrl        read from memory, then revoked

The <base> is the entry's own folder, so a fragment's relative URLs go straight to wherever it's hosted.

D · Requests per fragment boot

0Realm document. Comes from a blob. Never touches the network or session history.
1Entry module. An ordinary, cacheable script request, evaluated inside the realm.
nWhatever it asks for. Chunks, styles and data, fetched from its own folder.

E · What's next

Painted before JavaScript.

The gateway adds each app's content to the page as it streams, so people see it right away.

Apps you can't change.

One address for every app.

A registry you can roll back.
