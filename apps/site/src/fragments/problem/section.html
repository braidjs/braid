Why this
is hard

Four teams, one website. The usual fixes all go wrong somewhere.

Fix A

Make it one big app.

Now nobody ships alone. One team's broken build breaks everyone, and updating a library means getting every team to agree first.

What breaks: your release schedule.

Fix B

Put each app in an iframe.

Nicely separated, but each one is stuck in a box. It can't flow with the page, its pop-ups can't cover the page, and screen readers treat it as a different page.

What breaks: layout and accessibility.

Fix C

Load every app into one page.

It looks right, but the apps now share everything. Two versions of React collide, or one team's code quietly changes something another team relies on.

What breaks: something, on a Tuesday, with no clue why.
