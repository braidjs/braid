Path A · compat

Add an app you can't change.

Add the gateway to the server you already run. There's nothing new to deploy, and the app doesn't need a single code change.

$ npm i @braidlabs/gateway @braidlabs/core

const gateway = createGateway({
  registry: [{
    id: 'billing',
    endpoint: 'http://localhost:4201',
    pierce: ['/billing', '/billing/*'],
  }],
});
app.use(toNodeMiddleware(gateway));

<!-- then, wherever it should appear -->
<fragment-slot name="billing"></fragment-slot>

Path B · contract · no server

Build a site with no server, like this one.

Any static host will do. Each app is a script the page loads, and each one starts up from memory.

$ npm i @braidlabs/core

<!-- the page: any static HTML -->
<fragment-slot name="checkout"
  adapter="contract"
  entry="https://checkout.example.com/main.js">
</fragment-slot>

// the app: main.js
defineFragment({
  mount(env) { render(env.root); },
});
