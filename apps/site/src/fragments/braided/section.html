No server.
Yes, really.

This page is braided.

And there's no server behind it.

Each section you've scrolled past is its own little app. The page itself is just files on a CDN. When each app started, your browser built its sealed space from memory, using a blob: URL. Nothing had to be downloaded first, and your back button wasn't touched.

What happened while you read that

  1. 1The page finds a slot and reads which app goes there.
  2. 2Braid writes a tiny blank page for that app, in memory.
  3. 3It gives that page a blob: address, so no download is needed.
  4. 4A hidden frame opens it. That's the app's sealed space.
  5. 5The app's code loads and runs in there, away from everyone else.
  6. 6What it draws shows up here, on this page.
