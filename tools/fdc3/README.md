# FDC3 App Directory schema (test fixture)

`appd.schema.json` is the FDC3 App Directory v2 OpenAPI document, copied unmodified from
[finos/FDC3](https://github.com/finos/FDC3) at tag `v2.2.3`,
`packages/fdc3-standard/src/app-directory/specification/appd.schema.json`.

It is used only by tests, which validate the App Directory records Braid produces against it
(`validate-appd.ts`). It is not shipped in any package.
